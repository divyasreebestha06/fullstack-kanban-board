# 📋 fullstack-kanban-board

[![React](https://img.shields.io/badge/React-18-61DAFB?style=for-the-badge&logo=react&logoColor=black)](frontend/)
[![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=for-the-badge&logo=fastapi)](backend/)

Full-Stack Agile Kanban Sprint Board with React frontend, FastAPI backend, and drag-and-drop task workflow.

## Features
- **3-Stage Workflow:** To Do -> In Progress -> Done.
- **RESTful Endpoints:** Fast atomic card movements and board state retrieval.
- **Full-Stack Separation:** Modular React UI component and clean Python backend.
